Viikko 6 – Analytiikka ja CORS

Tässä tehtävässä React + Vite -sovellukseen lisättiin Cloudflare Web Analytics sekä käyttäjälle näytettävä suostumusbanneri, jossa kerrotaan analytiikan käytöstä.

Miten seurantaa voisi hyödyntää?

Analytiikan avulla voidaan arvioida sovelluksen teknistä toimivuutta ja käytettävyyttä. Sen avulla voidaan esimerkiksi nähdä, kuinka moni käyttäjä avaa sovelluksen, kirjautuu sisään, aloittaa pelin, lähettää arvauksen ja pelaa pelin loppuun asti. Analyytikalla sivua voi optimoida paremmin kun dataa on enemmän.

  • Käyttäjämäärien ja sivulatausten seuraaminen
  • Käyttöliittymän ongelmakohtien tunnistaminen
  • Teknisen toimivuuden arviointi eri selaimilla ja laitteilla
Analytiikan avulla voidaan tunnistaa, jos jokin vaihe sovelluksessa aiheuttaa ongelmia. Esimerkiksi jos on tilanne, jossa moni käyttäjä jää odottamaan pelaajia eikä peli käynnisty. Tässä tilanteesssa analytiikka voi paljastaa, että käyttöliittymä tai pelin aloituslogiikka vaatii selkeyttämistä.

Miten CORS-ongelman voisi välttää?

CORS-ongelmia voi välttää käyttämällä sovellusta aina HTTP- tai HTTPS-osoitteesta eikä avaamalla tiedostoja suoraan file://-polusta. Kehityksessä sovellusta tulisi ajaa Viten dev-serverillä ja tuotannossa esimerkiksi GitHub Pagesin kautta.

  • Käytä npm run dev kehityksessä
  • Käytä API-rajapintoja, jotka sallivat selainpyynnöt
  • Käytä tarvittaessa omaa backend- tai proxy-ratkaisua ulkoisiin API-kutsuihin

Cloudflare Web Analyticsin beacon kannattaa lisätä normaalina script-tagina sovelluksen HTML-tiedostoon eikä hakea sitä manuaalisesti JavaScriptin fetch-kutsulla.
